## F1 报告是怎样做出来的

按 `docs/strategy/科室研究脉络-方法论.md` 的 11 步执行（2026-10-17 开工，第 0–8 步于 10-18 完成，第 9–11 步见 README 状态）。13 个条目各由"调研员 → 核查员‖批评者 → 成稿人"四个子代理完成，核查员与批评者互不知道对方结论，成稿人拿到三份材料才动笔；全报告复核由 3 名抽查员 + 1 名跨章事实检查员 + 1 名跨章关系检查员承担；第一轮修订每章一名修订员，只改本章与本章证据表。执行器为 ZCode（无 Claude Code Workflow 工具），五个工作流的提示词逐段移植为 `scripts/zcode_prompts*.py`，各阶段结构化输出落盘到 `data/pipeline/` 并经 `validate` 校验必填键与枚举。

## F2 检索来源与访问限制

## F3 选读规则

关键节点只选承担六种作用之一的原始研究（提出问题/建立方法/验证或反证/改变认识/形成分支/划定边界），通常每章 8–16 个（实际 12–18，X01 为 28 个事件节点）；入口文献 3–8 篇记文中检索截止日；近五年按入口综述实际检索截止日补查；起点说法四类标注；阅读层级 L0–L4 如实、一行多层级取最低；研究数/报告数/患者数/专科计数单位分列；同一队列多篇报告标 same_cohort_as。本科室两处学科适配：① "中国线"改为"传承线 + 国际线"（本科室研究几乎全在中国，有意义的是学术思想接力链与海外独立验证/反驳）；② 专科计数单位字段名沿用 `n_wounds_flaps_other`、含义改为方剂/证候亚组/针灸疗程等。

## F8 过程偏差记录

1. **执行器差异**：方法论在 Claude Code Workflow 工具上验证，本次在 ZCode 上用 Agent 子代理 + 落盘 JSON + 轻量校验替代 StructuredOutput；`workflows/0x_*.js` 未运行，提示词在 `zcode_prompts*.py` 中按本科室改写，两套之间会漂移。
2. **样板方向自查发现检索日志漏记**（约 90 次只记 21 条），之后要求每次检索立刻追加到 `scratch/<ID>/search_log.jsonl`——这条改进在随后两次代理中断续跑时直接救回了 33 + 21 次检索。
3. **模型服务内容过滤中断**（D05 调研员，错误 1301）与**账户速率限制中断**（D02 核查员、D07 调研员，错误 1302）：共三例，全部换代理续跑成功；并发上限据此定为 8 个子代理。
4. **`sample_query_noise.py` 默认 `--retstart 1000`**，命中 <1000 的检索式抽到 0 条且不报错；D11 定稿口径须显式 `--retstart 0`。
5. **英文 "blood stasis" 双义**（中医血瘀 / Virchow 血液淤滞）与 `zheng[ti]` 命中姓氏，证候检索式三轮才收到可用噪声；B0 泛词限题名后噪声 12.5%。
6. **"中国线"概念对中医科室失效**，改为传承线 + 国际线并在 schema 加 `international_line` 必填字段。
7. **`qa_chapters.py` 引用正则只认单个 `[D03-N02]`**，成稿人写了复合引用 `[D03-N01/N02]`、`[D03-N02，L2]`，D03 被数成"引用 1"——脚本改为解析方括号组内全部编号；第一轮修订同时要求正文改回单个方括号。
8. **子代理落盘 JSON 的小格式漂移**（整数写成 hits、`data_and_design` 少 s、kind 复合值），`validate` 全部抓到，原则是脚本归一化不重跑代理。
9. **入口综述编号格式不一致**是机械质检"引用缺"的全部来源（正文 `[D04-E1]` vs 证据表 `D04-E01`/无 node_id），第一轮修订统一；D01 的 10 行入口由汇总者直接补 node_id E1–E10（只改证据表，正文未动）。
10. **汇总者凭印象写错一个数字**：README 首版把抽查"正确"写成 75（实为 74），F 成文时从 `qa_audit_rows.json` 重算后更正——与烧伤那次 F 里三个数字写错是同一类坑。
