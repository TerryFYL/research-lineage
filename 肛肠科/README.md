# 肛肠科研究脉络报告（含中医肛肠线）

> **状态声明**：本报告不是完整版。13 个条目（12 个方向 + 1 个学科史横切条目）自评与统一评级均为"基本完整但有标注缺口"。**全报告最大的共同缺口**：CNKI/万方未检索——中医肛肠文献的大头在中文库（《中国肛肠病杂志》1981 年创刊至今不入 MEDLINE），枯痔钉剂型改良、消痔灵早期剂量-并发症数据、丁泽民 1982 分段齿形结扎原文、TST 器械一手文献与大量中文 RCT 只到题录或转述层；各章第 8 节有本章的具体影响说明。另一共同缺口：ChiCTR 注册库不可程序化访问，注册终点核对依赖 ClinicalTrials.gov 与论文全文。
>
> **这仍然是一份可用的报告**：80 行证据分层抽查发现 2 处实质错误与 11 处小误差，已全部修复并留痕（修复前正确率 64/80，修复后逐行对账见各章"## 12 复核修订记录"）；全报告复核与两轮修订的留痕都在各章第 12 节。
>
> **依据**：`docs/strategy/科室研究脉络-方法论.md`（2026-10-02 版）。这是该方法**第三次实跑**（烧伤整形科 2026-09-29、中医心内科 2026-10-17→18），第一个"西医科室为主体+中医线并入"的混合口径科室（方向检索式不与中医块求交，中医线规模另设 B0/B0_herb）。执行器为 ZCode（Agent 子代理承担方法论里的五个工作流角色，移植件 `scripts/zcode_prompts*.py`）。
