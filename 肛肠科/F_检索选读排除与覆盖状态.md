## F2 检索来源与访问限制

**检索日志 1,195 条**（`data/F_search_log.csv`，逐条含来源与检索式）。来源分布（各章合计）：Europe PMC 及其 REST API 为主体，WebSearch、OpenAlex、Europe PMC fulltext、NCBI idconv、Crossref、WebFetch、PMC article page 为辅；注册库用 ClinicalTrials.gov API v2（ChiCTR 无 API，见下）。

访问限制（全部按纪律未绕过）：

1. **CNKI/万方无登录不可用**——本科室最大限制，中文核心临床期刊（《中国肛肠病杂志》《结直肠肛门外科》《中华胃肠外科杂志》部分早期卷）只能到题录或二手转述层；对中医线的影响逐章写入第 8 节。
2. PMC 反爬与 Cloudflare 拦截（消痔灵 1983 英文系列 PDF-only 三路皆阻；Europe PMC 渲染端点 403）。
3. ChiCTR 站内 API 不可直连（TRISDS 的 ChiCTR2000032941、针灸三项注册未独立核对）；PROSPERO 反爬=attended 访问非 0 条。
4. 付费墙：ASCRS/ESCP 指南正文、Lancet/NEJM 部分早期全文；相应表述一律降到题录+摘要层。
5. 中文 DOI 孤链：D09-EV-011（医药导报 2011）经 Crossref/doi.org/OpenAlex/Semantic Scholar/Europe PMC/万方六渠道不可达，已移待核线索（F6）。

## F3 选读规则

每方向三层：**起源与关键节点 13–27 个**（逐个核查：题录→摘要→可开放全文），**入口综述/指南 7–10 个**（定位学术地图），**近五年代表研究 12–30 个**（2021-10 至 2026-10 窗口，标成熟度）。阅读层级 L0 仅二手转述 / L1 题录已核 / L2 摘要已读 / L3 原文部分章节已读 / L4 全文已读；一行多层级按最低计。检索式 15 条（B0_herb/B0/C0+D01–D12）定稿前做了噪声抽样（`queries.py` 文件头与 `data/pubmed/noise_sampling_2026-10-18.md`）：B0 抽 40 判 24 相关/5 边缘/11 无关（27.5% 噪声，限用途）；最险的 D09 泛镇痛词口径抽 40 判 5 无关（12.5%），与前两科室定稿水平相当。

## F8 过程偏差记录

1. **执行器差异**：ZCode 无 Workflow 工具，五角色由 Agent 子代理承担（提示词移植件 `scripts/zcode_prompts*.py`）；并发上限 8（账号级限流 1302），超限触发 1301 内容过滤/1302 限流中断——D05/D07/D08 各中断过一次，均凭 `scratch/<ID>/search_log.jsonl` 与已下载材料续跑成功，未重复检索。
2. **B0 噪声 27.5% 高于前两科室（12.5%）**：机制不同（心内=泛病种词顺带出现；本科=继发便秘人群+中文文献不在库导致分母小），四轮收窄后判可用但限用途（E8-3）。
3. **任务书以文件为单一真源**：长任务书写入 `data/pipeline/prompts/<ID>_*.prompt.md`，子代理只传文件路径，避免脚本与任务书漂移。
4. **D08 批评者缺位**：管线并发限流跳过批评者环节；一轮修订以 qa_chapters 角色词检查+汇总者补偿检查替代，第 12 节已声明。
5. **mermaid 解析检查此前从未真正跑过**（依赖未安装）：本轮在 `scripts/` 补装 mermaid+jsdom 后全量解析，抓出 X01 两处 `-.|"…"|` 非法写法（此前只靠人眼）；已修，检查纳入脚本清单。
6. **审计发现未入一轮修订指令**：第 6 步的 80 行抽查发现（2 实质+11 小误差）当时只写进了 qa_audit_rows.json，未拆成第 7 步指令；2026-10-19 由汇总者逐行修复并补留痕。方法论提示：审计发现必须与 facts/relations 冲突同批进入修订指令。
7. **check_mermaid 的 `-.|"…"|` 陷阱**：dotted link 带引号标签的合法写法是 `-. "文字" .->`，`-.|"文字"|` 会报 Expecting LINK——两处均为成稿代理生成。
8. `sample_query_noise.py` 命中 <1000 时须 `--retstart 0`（默认 1000 会空转）。
9. **X01 证据行警示降权首例**：WJGS 2025 回顾队列源文自身至少四套口径互斥（复核抽查发现），证据行与正文同步加警示并降权——"源文内部不自洽"此前科室未遇到过，作为新缺口类型记录。
10. **派生表重建会冲掉手工补行**：`build_f_records.py` 从调研 JSON 重生成 F_*.csv，复核阶段手工追加到 CSV 的待核线索（D09-EV-011）被第二次重建冲掉；已加 `data/F_leads_extra.json` 持久入口，脚本重建时并入。教训：凡机器生成的表，补充内容只能进"源"或"extra 文件"，不能直接改产物。
11. **检查员结论也要复核**：第 9 步总览附录检查员判 X01 Longo 转述源 DOI"不可解析且证据表字段为空"，二轮修订员经 Crossref/doi.org 核验该 DOI 实可解析（Sturiale 2021 综述）并据此更正——完整性检查的"不可达/不存在"类结论与调研阶段同样可能是工具或时点造成的假阴性，修订员应复验而非照单全收（与 D09-EV-011 六渠道不可达的真阴性形成对照）。
